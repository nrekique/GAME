## Import Full Official Godot Editor Icon Set

If you have a local clone of `https://github.com/godotengine/godot`, run:

```bash
bash res://tb/fgd/entities/sprites/godot_svg_sources/godot_official_only/import_godot_editor_icons.sh /absolute/path/to/godot
```

This will copy all `editor/icons/*.svg` into this folder under `editor_icons/`.
